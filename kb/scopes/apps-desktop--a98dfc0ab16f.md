# Atet desktop context

The desktop workspace is Atet's complete local media host over the portable SDK contract. The closest guide owns the native capture, bounded host authority, deterministic Direct exclusion, and resource-admission rules. Keep portable graph contracts independent from native and product presentation code, and keep credentials and imported project data outside Git.

The repository-wide dependency and parallel-work contract lives in [[notes/repository-seams|repository seams]].
