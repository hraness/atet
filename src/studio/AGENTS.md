# Guidelines

- Parsing, inspection, and planning never read files, execute source, discover sibling files, or contact providers.
- Native authoring is explicitly trusted current-user code. Keep consent outside serialized requests and do not describe environment scrubbing or a working directory as a sandbox.
- Keep the engine registry closed. Retain source, cache, runtime, and output evidence without creating another project or scheduler.
- Preserve exact bundle paths and bytes, half-open frame ranges, reduced rational cadence, output roles, and declared color/coordinate interpretation.
- A successful receipt requires closed custody and exact declared output coverage. Unknown custody cannot imply cancellation completion or reusable outputs.
- Observed package fingerprints are not full runtime closure or hermetic execution evidence.
