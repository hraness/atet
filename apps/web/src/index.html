Installation guide View the source ↗

Bun 1.3.14+ · two commands

  1. 01 bun add --global github:hraness/atet
  2. 02 atet skill install

The second command installs the Codex skill for your user account. Start a new agent session, then ask it to use Atet.

How it works

From request to editable result.

One install gives your agent both the tool and the instructions to use it. Atet checks the work, coordinates local tools, and returns finished files to your workspace and keeps editable source when the work has one.

  1. 01
    Your request

    Describe the outcome in ordinary language.

  2. 02
    Agent + skill

    The agent uses the installed skill to choose a known Atet capability.

  3. 03
    Checked work

    Atet validates inputs and runs the work in your workspace.

  4. 04
    Results

    Files return to your workspace; source-based work keeps its editable source.

↳

Online only when needed. Model-backed creation goes from your local Atet process through Vercel AI Gateway. Local work stays local.

Why the design is dependable

Built for work you need to inspect.

Local custody
Project files and artifacts remain in storage you control.
No Atet account
There is no hosted project layer, auth service, or Atet credential store.
Source stays primary
In source-based and project workflows, working source remains authoritative over its exports.
Bounded work
Atet checks known capabilities and coordinates expensive jobs before they run.
