Agentic creative coding toolkit

Creative tools for coding agents.

Atet is a local toolkit that your agent runs inside a project to create images, editable diagrams, animation, and video. The command-line app does the work. The Agent Skill is a short guide that teaches Codex, Claude, or another coding agent how to use it.

Requires Bun 1.3.14+ · Installs for Codex by default

  1. 01bun add --global github:hraness/atet
  2. 02atet skill install
  3. 03atet doctor

Run atet doctor inside the project you want to work in. Then start a new agent session so it can see the skill.

Other setups

Choose where Atet installs its instructions.

The CLI is the program that does the work. The Agent Skill is a readable guide your agent uses to decide which command to run. By default, Atet installs that guide for Codex across your user account.

Claude Code
atet skill install --target claude
Other systems that read Agent Skills
atet skill install --target agents
Only the current repository
Run the install there and add --scope project.

Use

Ask for a result, not a command.

Open the project that contains your source files, start a new agent session, and mention Atet in your request. Say which file or subject to use and what you want to receive. Your agent will choose and run the commands.

“Use Atet to turn the services in this repository into a diagram I can edit later.”
“Use Atet to convert logo.png into a clean SVG. Keep the original PNG unchanged.”
“Use Atet to create three cover-image ideas for this article and show them to me side by side.”
“Use Atet to turn reference.png into a seamless five-second 3D loop with a transparent background.”
“Use Atet to render this logo as polished metal on a plain background. Keep the original shape recognizable.”

After it runs, your agent should show you the result, tell you where the files were saved, and keep editable source when Atet creates it. You can ask for changes in the same way. You do not need to learn the CLI first.

Features

Images, diagrams, animation, and video.

Atet uses one project system for four kinds of visual output. Work can begin with files you already have, a plain-language description, or both.

Images
Create an image through Vercel AI Gateway, or convert artwork you already own into SVG on your computer.
Diagrams
Turn an explanation into an editable diagram with tldraw, SVG, and PNG exports.
Animated loops
Build repeatable motion with editable HTML, SVG, shader, or Three.js source.
Video
Combine recordings, graphics, sound, captions, and alternate formats in one local project.

How people and software use it

Most people install the Agent Skill and talk to their coding agent. Underneath, the agent runs the Atet CLI. Developers can call the same tools through the TypeScript SDK or MCP server. The macOS desktop app uses the same local project files and adds screen capture and previews.

Design

Your files stay in your project.

Atet is not a web app and does not have user accounts. It runs on your computer and writes source files, previews, and final outputs to storage you control. When a task needs a generative model, your local Atet process sends that request through your own Vercel AI Gateway credential.

  1. 01
    Request

    You describe what you want and point to any source files.

  2. 02
    Choose

    Your agent selects the Atet tool made for that kind of work.

  3. 03
    Run

    Atet checks the inputs, then works locally or calls the configured model provider.

  4. 04
    Review

    The files are saved in your project and your agent shows you what changed.

No Atet account
There is no hosted project database, login, or subscription.
Local wherever possible
Diagrams, vectorization, project state, and deterministic rendering stay on the computer running Atet.
Editable work stays editable
Diagrams, scenes, and media projects keep their source instead of leaving only a flattened export.
Clear limits
Atet checks file types, paths, dimensions, response sizes, process duration, and expensive concurrent work.
A record of what happened
Important model and media operations record what created the output without including credentials.

Atet checks its commands, not every program on your computer

Atet validates the inputs accepted by its own tools. It is not an operating-system sandbox. A script you deliberately run in a project has the same permissions as other code running under your user account.

For technical readers

The installed skill and atet --help describe the commands available on the current machine. The repository documents the project model, security boundary, and source for people who want to inspect the implementation.
