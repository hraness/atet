Use

Ask for the result you want.

Open a project and tell your agent to use Atet. The installed skill teaches it how to choose a capability, keep editable source when the work has one, run the work, and review the result.

“Use Atet to turn this repository architecture into a clear diagram.”
“Use Atet to vectorize this mark and keep the original beside the reusable asset.”
“Use Atet to create three image directions for this chapter and help me compare them.”
“Use Atet to build a seamless animated loop from this reference image.”
“Use Atet to review this video project and explain the next checked step.”

You do not need to learn the command tree first. The installed skill and built-in help give your agent the exact instructions for the code on your machine.

Features

Four forms. One way of working.

Atet uses the same inspectable project model across four kinds of creative output. Each can begin as a plain-language request.

Images
Create new imagery or turn existing artwork into clean, reusable assets.
Diagrams
Turn an explanation into checked, editable visual source and publication-ready outputs.
Animated loops
Build timed scenes and repeatable motion that can be revised or reused.
Video
Compose recordings, visuals, sound, captions, and delivery variants as one project.

Several ways in, one underlying system.

The Agent Skill is the default human entry point. The CLI and local runtime perform the work. Software integrations can use the same checked capabilities, while the macOS desktop app adds native capture without creating a second project model.

Design

Local work with an explicit online boundary.

Atet runs in your workspace. It validates the plan and inputs, coordinates local tools, and writes results back to storage you control. Only work that needs a model is sent through Vercel AI Gateway.

  1. 01
    Intent

    You describe the result.

  2. 02
    Plan

    The agent chooses a known Atet capability.

  3. 03
    Execution

    Atet runs local work or calls the configured model provider when required.

  4. 04
    Result

    Files return to your workspace; source-based work also keeps its editable source.

Caller-owned storage
Atet does not operate a hosted project database or account system.
Explicit provider use
Gateway credentials are supplied by your local process and are not stored by Atet.
Source before output
Source-based and project workflows keep their working source available for inspection and revision.
Checked, bounded work
Atet validates known capabilities and coordinates expensive jobs before they run.
Traceable results
Important generation and media results keep enough identity to connect them to their source and plan.

An honest boundary

Atet checks its own capabilities; it is not an operating-system sandbox. Code you deliberately add to a project keeps the same trust as other code you run there.

Exact details, when you need them.
