Open-source visual media workflows in code

Atet

Move visual media from source to final.

Generate images, build editable diagrams, author animated loops, and compose video from one typed project. Atet runs through a TypeScript SDK, a Bun CLI, and a local runtime that keeps the work inspectable.

Name Atet draws on Ra's solar barque as an abstract metaphor for passage and transformation: sources enter one vessel, move through explicit operations, and arrive as exact outputs.

Four output families

Choose the form. Keep the source.

Every fixed export remains connected to the project and operations that produced it.

01 Images
Generate through Vercel AI Gateway, vectorize references, or render stills with code.
02 Diagrams
Build checked, editable tldraw sources and render SVG or PNG derivatives when delivery needs a fixed asset.
03 Animated loops
Author deterministic HTML, CSS, SVG, Canvas, WebGL, Three.js, or shader scenes with explicit timing.
04 Video
Compose recordings, images, diagrams, loops, audio, captions, and overlays into every required aspect ratio.

Performance without hidden state

Iteration stays fast because identity stays exact.

Cache by proof

A verified artifact with the same inputs, source revision, operation, renderer, toolchain, and output profile can be adopted. A meaningful change creates a new identity.

Fork candidates safely

Agents render independent candidates without sharing mutable files. Selection is explicit, and stale promotion fails closed while preserving every branch.

Preview the whole piece

The default preview keeps complete duration while reducing spatial quality and selecting a faster encoder recipe.

Render final on purpose

Independent work runs in parallel within one machine ceiling. Expensive video encodes serialize by default, and partial verified results remain reusable.

One system, three boundaries

Use the smallest surface the work needs.

TypeScript SDK
Define, validate, compile, and run typed visual graphs inside a Bun script or agent host.
Local host
Schedule durable media work, enforce resource ceilings, recover runs, and publish verified artifacts.
Desktop shell
Add screen, camera, and microphone capture plus native permissions without creating another workflow engine.

Local by default

Bring Atet to the work.

Atet has no hosted account or browser generation service. The local SDK and CLI read AI_GATEWAY_API_KEY or Vercel's short-lived VERCEL_OIDC_TOKEN. This site never receives either credential.

Local media stays local unless a workflow explicitly sends a bounded input to a generation provider.
