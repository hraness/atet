Transmute

Transmute is an open-source system for turning an idea, sketch, recording, or raw asset into a finished visual. Use it as a TypeScript SDK in a Bun script, as a local media host, or through the desktop shell when a workflow needs screen, camera, or microphone capture.

Outputs

Images
Generate through Vercel AI Gateway, vectorize raster references, or render stills with code. Reference-led treatments can bind an input image to reviewed Three.js geometry, materials, lighting, and camera decisions, including metallic logo product renders.
Diagrams
Build a checked, editable tldraw source with explicit layout and styling. Render SVG or PNG derivatives when a fixed asset is needed without trapping the diagram in that export.
Animated loops
Author deterministic HTML, CSS, SVG, Canvas, WebGL, Three.js, or shader scenes. Render finite loops with explicit timing and an optional transparent background for reuse in another composition.
Video
Compose recordings, images, diagrams, loops, audio, transcripts, captions, and overlays. Derive clean and captioned exports for 16:9, 9:16, 1:1, 4:5, or a custom target from the same edit.

One project

A project is an immutable graph of sources, operations, and artifacts. Captions, crops, aspect ratios, quality tiers, and delivery formats are independent variants of one edit, not copies that drift apart. The SDK defines and validates that graph. The local host schedules durable media work and recovery. The desktop shell adds native capture and permissions; it does not introduce another workflow engine.

Identity and reuse

Each derivation is identified by its exact inputs, source revision, operation, renderer, toolchain, and output profile. A verified artifact with the same identity can be adopted instead of rendered again. A meaningful change creates a new identity, so caching never guesses that two different runs are equivalent and partial results remain reusable.

Parallel iteration

Agents can fork independent candidates from one frozen project revision, render each candidate, and compare them without sharing mutable files. Selection and promotion are explicit. If the project changed underneath a candidate, promotion fails closed and preserves every branch instead of silently merging conflicting editorial work.

Preview and final render

The default preview keeps the complete duration while lowering spatial quality and choosing a faster encoder recipe. Final quality is an explicit render after selection. A machine-level scheduler keeps ready work inside one resource ceiling, runs independent work in parallel when it fits, and serializes expensive video encodes by default so FFmpeg does not compete with itself.

Bring your own Gateway access

Transmute has no hosted account or browser generation service. Local SDK and CLI processes read AI_GATEWAY_API_KEY or Vercel's short-lived VERCEL_OIDC_TOKEN. With a linked Vercel project, inject the environment for one command without writing a credential into the project: 

vercel link
vercel env run -- bun run render.ts

Local media stays local unless a workflow explicitly sends a bounded input to a generation provider. The website never receives a Gateway credential.
